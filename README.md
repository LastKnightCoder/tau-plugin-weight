# 减重

记下早晚体重、吃了什么、运动了多久，随时看到「今天还能吃多少」。少吃、多动由记录自动判定，图表和 AI 帮你看清哪样更管用。

## 能做什么

- **称体重**：起床、睡前各记一次。趋势只看晨重的 7 日均值，单日波动不用在意；睡前体重用来看当天吃得多不多。
- **一句话记录**：吃之前写一句「奶茶一杯」，还没记下就能看到热量和记下后还剩多少。运动写「跑步 30 分钟」，消耗会加回当天的余额。热量由 AI 估算，可以直接改；改过的数字会被记住，下次不再估算。
- **每日预算**：按身高、年龄、性别和当前体重算出日常消耗，再减 500 kcal。体重下降后预算自动下调，也可以手动固定一个数。
- **自动打卡**：没超预算算「少吃」，运动达到目标分钟数算「多动」，不用手动打勾。
- **看趋势**：体重和每天的摄入画在同一条时间轴上，哪天超了、几天后体重有没有回升一眼就能对上。
- **看效果**：按「都做到 / 只少吃 / 只多动 / 都没做」比较第二天晨重的变化，看哪样对你更有效。
- **AI 分析**：「今天」告诉你晚饭还能吃多少、运动还差多少；「本周」总结趋势和容易破功的规律。
- **首页卡片**：在「今日」首页直接称重、记一笔。

## 开始使用

1. 在插件中心安装并启用「减重」。
2. 打开插件详情的「设置」，填写身高、出生年份和性别，可选填目标体重。
3. 点侧边栏的「减重」，明早起床称一次，之后吃东西、运动前写一句。

## 常见问题

**AI 能看到什么？** 只有体重、热量，以及你写下的饮食和运动文字，不读取你的其他笔记。AI 使用你为「对话功能」分配的模型，第一次使用时会询问授权，可以在插件详情的「权限」中撤销。不用 AI 也可以，自己填热量即可。

**没配置 AI 模型能用吗？** 能。估算失败时直接填热量，常吃的东西记一次以后会自动带出。

**数据会同步吗？** 会。体重和记录存在笔记库里，随笔记库一起同步。

**热量预算准吗？** 这是基于公式的估算，适合用来约束自己，不能代替医生或营养师的建议。连续两三周体重不降时，可以在设置里把预算调低一些。
